# Frontend Embellecedor — Suite Maestra de Ingeniería y Diseño UI/UX

Esta carpeta reúne la suite completa de diseño, dirección de arte, micro-interacciones y sistemas visuales de clase mundial:

```
frontend_embellecedor/
├── emilkowalski-skill/       # Emil Kowalski: Design Engineering, animaciones, gestos, coreografía y vocabulario UI
├── impeccable-upstream/      # Impeccable (v4.9.0): Auditoría visual, /polish, /critique, /audit y anti-patrones
├── taste-skill/              # Leonxlnx Taste Skill (v2.5.1): Dirección de arte, tipografía cuidada y estética web
├── ui-pro-max/               # Componentes obsidian, glassmorphism y spotlight interactivo
├── impecable/                # Reglas matemáticas 8pt, escala modular y WCAG AAA
├── skill-ul/                 # Listas dinámicas, progress bars con shimmer y widgets
└── index.html                # Showcase interactivo
```

---

## Módulos y Funciones Clave

| Módulo | Repositorio | Enfoque Principal |
| :--- | :--- | :--- |
| **Emil Kowalski Skills** | `emilkowalski/skill` | Ingeniería de diseño, coreografía de animaciones, resortes y micro-interacciones de alto impacto. |
| **Impeccable Upstream** | `pbakaus/impeccable` | Comandos de auditoría de diseño (`/audit`, `/critique`, `/polish`) y erradicación de anti-patrones visuales de IA. |
| **Design Taste** | `Leonxlnx/taste-skill` | Dirección artística deliberada, tipografía refinada, ritmo editorial y layouts únicos. |
| **UI Pro Max** | Integración Local | Glassmorphism translúcido, tarjetas spotlight con rastreo de puntero y paleta Obsidian. |
| **Impeccable Core** | Integración Local | Grilla geométrica 4/8pt, contraste verificado AAA y micro-estados suaves. |
| **Skill-UL** | Integración Local | Listas estilizadas, badges reactivos con destellos shimmer y widgets interactivos. |
